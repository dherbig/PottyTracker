# Potty Tracker

Track when your dog was last taken out for a potty break. React PWA + self-hosted API, with ESP32 physical clock sync planned.

## Quick start

```bash
pnpm install
pnpm test
pnpm dev
```

## GitHub setup

1. Create a repository on GitHub
2. Add the remote:

```bash
git remote add origin git@github.com:YOUR_USER/PottyTracker.git
```

3. Push when ready (after review):

```bash
git push -u origin main
```
